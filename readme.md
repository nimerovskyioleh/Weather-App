# ☁️ Modern Weather App

A mobile application built with **React Native** and **Expo** that provides real-time weather data and 5-day forecasts.

## 🚀 Features

- **Location-based Weather:** Automatically detects your city using GPS.
- **City Search:** Search for weather data in any city worldwide.
- **Authentication:** Secure login and sign-up using **Firebase**.
- **Offline Support:** Caches recent weather data for offline access.
- **Clean UI:** Responsive design with Lucide icons.

## 🛠 Tech Stack

- **Framework:** React Native (Expo)
- **State Management:** Zustand
- **API:** OpenWeatherMap
- **Backend:** Firebase Authentication
- **Storage:** AsyncStorage & Expo SecureStore

## 📦 Installation

1. Clone the repo: `git clone https://github.com/nimerovskyioleh/Weather-App.git`
2. Install dependencies: `npm install`
3. Create a `.env` file and add keys
4. Run the app: `npx expo start`
